# Random Forest

Random Forest is a machine learning algorithm that combines many decision trees to make more reliable predictions.

- **Classification:** trees vote on a class.
- **Regression:** tree predictions are averaged.

## How it works

1. Each tree trains on a random sample of the data.
2. Each split considers a random subset of features.
3. The forest combines the trees’ predictions.

It is useful for many prediction tasks, but can be slower and harder to explain than a single tree.
